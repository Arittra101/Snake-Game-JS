# Snake Game JS 🐍

A classic Snake game built with JavaScript, HTML, and CSS. Play the timeless arcade game directly in your browser!

## 🎮 Live Demo

[Click here to play the game](https://kaleidoscopic-biscuit-3e11bf.netlify.app/)

## 📋 Features

- Classic gameplay with smooth controls
- Responsive browser-based design
- Score tracking as you collect food
- Game over detection for wall and self-collision
- Simple, lightweight implementation with no dependencies

## 🎯 How to Play

1. Open the game in your browser
2. Use the arrow keys or WASD to move the snake
3. Eat the food to grow longer and increase your score
4. Avoid hitting the walls or your own body
5. Try to beat your highest score

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🚀 Getting Started

### Prerequisites

- A modern web browser

### Run Locally

1. Clone the repository:
```bash
git clone https://github.com/Arittra101/Snake-Game-JS.git
```

2. Open the project folder:
```bash
cd Snake-Game-JS
```

3. Launch `index.html` in your browser.
